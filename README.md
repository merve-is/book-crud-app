# Make Books Collection 📚

A simple and modern book management app built with React and TypeScript.

Users can add, edit, delete, search, and view book details in a clean interface.

## Features

* Add new books
* Edit existing books
* Delete books
* Search books with query params
* View book details
* Previous / Next book navigation
* Loading and error states
* 404 Not Found page
* Responsive grid layout

## Tech Stack

* React
* TypeScript
* React Router
* Axios
* Tailwind CSS
* DaisyUI
* JSON Server

## Getting Started

### Install dependencies

```bash
npm install
```

### Run the project

```bash
npm run dev
```

### Run JSON Server

```bash
npx json-server db.json
```
